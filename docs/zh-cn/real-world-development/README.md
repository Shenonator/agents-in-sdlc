使用真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在整个软件开发生命周期中的应用。你将通过迭代方式规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，提供面向开发者的棋盘游戏众筹平台。团队的待办事项已作为 GitHub issue 创建完毕，可以随时开始处理。其中包括筛选和分页等功能任务，也包括无障碍和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合自己构建方式的工作环境。每个研讨会都有独立的设置流程，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理助手。体验 Plan 和 Autopilot 模式、说明、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot 应用][app]

在桌面应用中运行并行代理会话、切换会话模式、协作处理 Canvas，并管理 GitHub issue 和拉取请求。

### [GitHub Copilot 云代理][cloud]

将 GitHub issue 分配给异步代理、引导其工作、监控进度并审查其创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat Agent 模式、MCP 服务器和自定义代理。
