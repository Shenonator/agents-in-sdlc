フィルター機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストはすべて1つのブランチに保存されています。まとめてレビューし、プルリクエストを作成します。星評価のプルリクエスト (PR) は自分でマージしましたが、今回は **Agent Merge** にプロセスを管理させます。

> [!NOTE]
> 通常は、機能、指示の更新、スキルの更新、QA エージェントを複数の PR に分けます。ワークショップを簡潔に進めるため、フィルター機能と品質に関するワークフロー全体を1つのセッションとブランチにまとめ、そのすべての作業をこの PR に含めています。

このレッスンでは、次の操作を行います。

- Agent Merge とは何か、マージまでの流れをどのように自動化するかを学びます。
- 機能の PR 全体と検証の証拠を確認します。
- レビュー後にのみ Agent Merge を許可し、PR がマージされたことを確認します。

## シナリオ

フィルター機能のワークフローを通じて、Copilot を使って機能を計画、実装、検証しました。Tailspin Toys では、開発者がマージを許可する権限を保ったまま、残りの PR 作業を自動化したいと考えています。

## Agent Merge について

**Agent Merge** を使うと、GitHub Copilot app でプルリクエストを取り込むまでの残りの作業を自動化できます。有効にすると、アプリのセッションがプルリクエストを読み取り、失敗した継続的インテグレーション (CI) チェックの修正、レビューコメントへの対応、必要に応じたリベースなど、マージを妨げる問題に対処します。GitHub で許可され次第マージします。バックグラウンドで動作し、アプリを再起動しても継続し、プルリクエストがマージされると自動的に停止します。

ここまでは、自分で **Merge pull request** を選択していました。Agent Merge にその役割を任せることもできますが、コードの編集やマージには引き続き明示的な承認が必要です。マージ権限を与える前に、許可される操作と作業内容をレビューしてください。

## Agent Merge で PR を管理する

コードの作成とレビューが完了したので、Agent Merge に PR プロセスを管理させます。

1. エージェント ピッカーで **Default agent** を選択します。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択してプロセスを開始します。ドロップダウンの項目を選んだだけでは開始されません。

Agent Merge のプロセスが始まります。次の処理を行います。

- タイトルと説明を含むプルリクエストを作成します。
- Issue からセッションを開始した場合は、説明の本文で関連する Issue を参照します。
- ターゲット ブランチへのリベース、またはマージ競合への対応を行います。
- CI プロセスを監視し、すべてのチェックが成功することを確認します。
- ほかの開発者や Copilot code review からのフィードバックがないか PR を監視し、コメントを解決するために更新します。
- 必要に応じて、すべてのチェックが成功した後に PR を自動的にマージします。

すべてのチェックが成功した後に PR もマージするよう、Agent Merge に許可します。

5. マージを許可する前に、PR の差分と検証の証拠をレビューします。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. 次のように明示して、エージェントにマージを依頼します。

    ```plaintext
    Merge the PR once all required checks and approvals pass. Do not bypass repository protections.
    ```

9. 進捗を確認し、報告されたブロッカーを解消します。続行前に、PR の状態が **Merged** であることを確認します。マージ権限が有効になっていることや、エージェントが実行中であることは、マージ完了の証明ではありません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護や権限不足を回避しません。続行する前にそれらの阻害要因を解消してください。
